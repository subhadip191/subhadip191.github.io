# Subhadip Maity | Portfolio

Personal portfolio website showcasing my projects in data science, machine learning and data engineering.

**Live site:** https://subhadip191.github.io

## About

I'm an MSc Data Science student at the University of Naples Federico II, aiming for Data Scientist and AI Engineer roles. This site collects my projects, skills and contact details in one place.

## Featured projects

- **Cardiac Disease Detection:** ECG image classification with MobileNetV2, patient-level data leakage correction and Grad-CAM interpretability.
- **Real-Time Tweet Sentiment Analysis:** streaming pipeline built with Apache Kafka and PySpark.
- **Bibliometric ETL:** a source-agnostic ETL pipeline extending bibliometrix-python.
- **Voice-to-Query:** a speech-to-SQL pipeline.
